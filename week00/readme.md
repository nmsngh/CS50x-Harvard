# CS50x Week 0: Scratch Project

## 🐱 Project Title: Catch the Beetle

### 📌 Project Overview
This is a basic Scratch project created for **Harvard CS50x** to demonstrate the fundamental concept of automated loops and event-driven programming.

### 🚀 Key Features & Logic
Used a 'Repeat' loop to automate 10 consecutive cycles of sprite movement and interaction logic.
